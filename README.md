# 소방설비기사 문제풀이

소방원론·소방전기회로·소방관계법규·소방전기시설의 구조 및 원리·소방설비기사 전기 Anki 자료를 브라우저에서 풀어 보는 정적 학습 앱입니다.

## 실행

저장소의 **Settings → Pages**에서 GitHub Actions 배포를 선택하면 됩니다. 배포가 완료되면 과목을 선택하고 문항 수를 정해 문제를 풀 수 있습니다.

문항 데이터는 `theme-bank.json`과 `themes/`에 있는 5개 학습 테마에서 생성됩니다. 법령과 화재안전기준은 개정될 수 있으므로 실제 시험이나 현장 업무에는 최신 공식 원문을 확인하세요.

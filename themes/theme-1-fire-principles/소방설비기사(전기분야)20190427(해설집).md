## 4. 문제

4. 공기의 부피 비율이 질소 79%, 산소 21%인 전기실에 화재가 
발생하여 이산화탄소 소화약제를 방출하여 소화하였다. 이때 
산소의 부피농도가 14%이었다면 이 혼합 공기의 분자량은 
약 얼마인가? (단, 화재시 발생한 연소가스는 무시한다.)
   ① 28.9
② 30.9
   ③ 33.9
④ 35.9
<문제 해설>
방출후
1) 산소 14%
2) 이산화탄소 체적 = (21-O2/21)*100 = 21-14/21*100 = 
33.3%
3) 질소체적 = 100-산소-이산화탄소 = 100-14-33 = 53%
공기분자량 산소(32=16*2)*0.14+이산화탄소44=12+16*2)*0.33+
질소(28=14*2)*0.53 = 33.9
[해설작성자 : 와그라노]
산소의 부피농도 : 14%
이산화탄소 체적 = ((21-O2)/21)*100 = ((21-14)/21)*100 = 
33.3[%]
질소의 체적 = 100-산소부피농도-이산화탄소체적 = 
100-14-33.3 = 52.7[%]
공기의 분자량 = (산소분자량*산소농도)+(이산화탄소분자량*이
산화탄소농도)+(질소분자량*질소농도)
                            = 
(32*0.14)+(44*0.33)+(28*0.53) = 33.84 = 33.9
[해설작성자 : comcbt.com 이용자]
이런 종류의 문제는 간단하게 암산으로 풀수 있습니다..
산소가 21% -> 14%로 변경되었으므로 1/3만큼 줄어들었음을 
알수 있습니다..
따라서 기존의 공기비중이 3/2이고 이산화탄소비중이 1/3입니
다..
공기의 분자량이 29(30-1)이고 이산화탄소의 분자량이 
44(45-1)이므로,
평균값은 30과 45 사이에서 3등분 중    30에 2배 가중되어(이
산화탄소보다 공기의 비중이 2배 더 많음) 존재하게 됩니다..
따라서 35정도이며 계산의 편리를 위해서 1을 더했으므로 실제
